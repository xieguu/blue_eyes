# CareEyes Pro 开发日志

本日志记录项目版本变更，随源码在 `docs/` 目录维护。

## [v5.5] - 2026-09-20

### 新增
- 在休息页与托盘提供 15 / 30 / 60 分钟临时免打扰，以及提前恢复入口；护眼和用眼统计继续运行，原工作倒计时不重置。
- 在统计页提供 CSV 导出，包含最近 32 个自然日内已有的每日用眼分钟数，使用 UTF-8 BOM 和原子写入。
- 增加 `docs/IMPROVEMENTS.md`，记录同类开源工具调研、官方组件选型及后续功能优先级。

### 优化与修复
- 用 Qt `QTimeLine` 替换按回调次数累积的渐变，避免事件循环延迟后逐帧补跑；连续切换从最近成功应用的帧开始，停止后的迟到回调不再写显示设备。
- 配置和导出统一使用 `QSaveFile`，关闭直接覆盖回退；写入/提交失败保留原文件，配置错误显示在设置页，不再静默吞掉。
- 配置序列化拒绝 NaN / Infinity；保存和导出共享历史记录过滤逻辑。
- 主程序与 Windows 文件版本统一为 5.5。
- 为包含中文的构建脚本补上 UTF-8 BOM，修复 Windows PowerShell 5.1 下中文提示和变量插值被错误解析的问题。

### 验证与兼容
- 测试从 107 项增至 137 项，覆盖免打扰与活动统计的独立性、恢复/到期、菜单同步、CSV 边界、写盘失败及渐变延迟。
- 使用离屏渲染检查 860×640 和 760×560 窗口布局，不启用真实 Gamma 写入。
- 完成 PyInstaller 构建，核对 EXE 5.5.0 文件版本、运行模块及 SHA256；产物约 36.52 MiB，校验值更新至 `CareEyesPro.exe.sha256`。
- 保留既有配置结构、桌宠成长和服装选择；临时免打扰不落盘。未调整原有休息启动次数的历史含义。

## [v5.4] - 2026-09-19

### 新增
- 按桌宠概念图增加四件衣柜、组合穿戴、等级条和下一件奖励进度；三款主角直接展示，其余外观和互动区可展开，小窗口支持纵向滚动。
- 每次完整休息获得 10 成长值，每 20 成长值升一级；星星别针在累计 6 次完整休息解锁，晚安帽在 12 次解锁。
- 围巾、头饰、别针支持组合；小芽与晚安帽共用头饰位置，全部外观共享等级和衣柜，切换时保留穿搭。
- 新增 `pet_completed_rests`、`pet_outfit` 存档字段，兼容旧设置；奖励及穿戴修改立即原子保存。

### 优化
- 桌宠和页面预览按可见性启停动画；统计页按需采样，窗口隐藏或最小化后停止无效的页面后台工作。
- 倒计时只刷新可见的桌宠页面，消除每秒重复同步；相同的预览状态不再触发重绘。
- 使用标准库有界缓存复用不可变 Gamma 曲线，保留每次驱动写入、失败反馈和原始曲线恢复。
- 重绘九款桌宠：统一低饱和配色、柔光渐变和柔和阴影，补充猫耳、狐尾、兔耳、羽纹、卷毛与像素机身细节。
- 统一眨眼、视线跟随和状态表情，挠痒痒与开心彩蛋使用笑眼，休息提示改为不依赖字体的矢量绘制。
- 围巾和小芽按角色适配；机器人使用像素化配饰，保留完整心形指示灯。

### 修复
- 区分休息完成、提前跳过和取消；通过遮罩身份校验阻止重复结算，退出及重置不发放奖励。
- 退出时显式停止桌宠预览定时器；桌宠隐藏时清理气泡计时，重新显示后正常恢复。
- 主程序和 Windows EXE 元数据统一升级至 v5.4，README 色温范围修正为实际支持的 2000K–8000K。
- 修复紫鸮缺少眨眼/闭眼表现，以及桌宠捏压、拉伸和抛掷时耳朵或尾巴被窗口裁切的问题。

### 测试与预览
- 新增成长/奖励阈值、装备槽互斥、结算幂等、旧存档兼容和组合穿戴绘制回归测试。
- 新增 `docs/previews/render_pet_studio.py`，使用临时配置渲染真实桌宠中心，不修改用户进度和显示设置。
- 新增 Gamma 缓存、硬件写入重试、隐藏/最小化后的定时器生命周期、按需采样和去重刷新回归测试。
- 新增原生尺寸边界、缩略图、高 DPI、表情、配饰遮挡和互动姿态回归测试。
- 新增 `docs/previews/render_pet_gallery.py`，离屏生成九款外观与四种状态的真实效果图。

### 兼容说明
- 旧存档保留已有外观和设置，成长从 Lv.1 开始，不把历史休息启动次数当作完成次数；重置所有设置会同时清空成长和穿戴。

## [v5.3] - 2026-09-14

### 新增
- 桌宠皮肤扩展为 9 款，加入概念图中的小海鸥、奶油猫和像素机器人，并适配正常、疲劳、休息和关闭状态。
- 桌宠从设置页拆分为独立导航页面，加入动态大预览、皮肤卡片、启停控制、陪伴状态和休息进度展示。
- 桌宠新增“捏一捏、拉长长、挠痒痒、抛一下、轻戳”五种互动玩法，支持阻尼回弹、抛掷落地、粒子反馈、双击彩蛋与模式持久化。
- 默认玩法设为“自由移动”，左键拖动可调整桌宠位置；切换到互动玩法后使用 `Shift + 拖动`移动，避免拖动手势冲突。

### 变更
- CareEyes Pro 主程序与 Windows EXE 元数据升级至 v5.3。

## [v5.2] - 2026-09-09

### 新增
- 桌面宠物（DesktopPet）：纯 QPainter 绘制，跟随护眼状态切换表情；脚下进度条显示距离下次休息的进度；支持戳一戳反应、拖动贴边、位置记忆；右键菜单含“打开主界面 / 立即休息 / 切换护眼 / 藏起来 / 退出”；托盘与设置页均可开关，状态写入配置。
- 顶部紧凑导航替代宽侧边栏，界面占用更小、信息密度更高。
- 系统指标采集：CPU/内存/运行时间（WinAPI，非管理员时降级为不可用），统计页展示。
- 精简 PyInstaller 构建配置（`CareEyesPro.spec`、`build.ps1`）与 Windows 版本信息（`version_info.txt`）。
- 护眼监控与统计增强（`26b2ade`）。

### 修复
- 安全 Gamma 恢复与空闲感知调度（`d1f4f36`）：退出/异常时按记录恢复原始 Gamma 曲线；空闲暂停不累计工作时长；全屏检测顺延休息 5 分钟，并区分白名单（不推迟）/ 强制推迟（如 javaw.exe）。
- 配置写盘改为“临时文件 + 原子替换”，降低异常退出导致的配置损坏。

### 移除
- 去除未使用的 `pywin32` 依赖；`requirements.txt` 收敛为 `PyQt5`、`pynput` 两项。
- 清理废弃文件与缓存（`ce69051`）。

### 已知问题
- Gamma 修改对部分独占全屏程序/管理员程序无效，需以管理员身份运行。
- 显卡驱动更新或系统恢复默认可能覆盖 Gamma，需重新开关护眼。
